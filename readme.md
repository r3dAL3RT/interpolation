# Аппроксимация функций методом наименьших квадратов (МНК)

Программа на Python для аппроксимации зашумленных данных многочленами различных степеней с использованием классических нормальных уравнений и системы ортогональных полиномов.

## Описание работы

1. **Генерация данных:**
   * Целевая функция: $f(x) = \sqrt{x+1} - \cos(x)$ на отрезке $x \in [-1, 1]$.
   * В каждой из 50 точек генерируются 3 зашумленных значения с равномерным распределением шума $\pm\delta$ ($\delta = 0.07$).

2. **Методы аппроксимации:**
   * **Решение системы нормальных уравнений:** Построение матрицы Вандермонда и решение СЛАУ методом наименьших квадратов.
   * **Ортогональные полиномы:** Построение базиса ортогональных многочленов с помощью рекуррентных соотношений и вычисление коэффициентов аппроксимации.

3. **Сравнение:**
   * Вычисление суммы квадратов неувязок $S$ для обоих методов при степенях многочлена $n \in [1, 5]$.
   * Визуализация результатов аппроксимации и исходных экспериментальных данных.

## Зависимости

* Python 3.x
* `numpy`
* `matplotlib`

## Запуск

```bash
python Группа_24.Б04_Бусыгин_Аппроксимация.py
```

После запуска программа выведет в консоль таблицу сумм квадратов неувязок для каждого метода и последовательно отобразит графики аппроксимации для степеней $n$ от 1 до 5.
